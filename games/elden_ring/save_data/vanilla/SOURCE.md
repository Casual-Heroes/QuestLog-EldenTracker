# Source

Reference data in this folder (item/boss/grace/event-flag ID tables) is ported from
[CasualHeroes/Elden-Ring-Automatic-Checklist](https://github.com/CasualHeroes/Elden-Ring-Automatic-Checklist)
(fork of `CyberGiant7/Elden-Ring-Automatic-Checklist`), MIT License, Copyright (c) 2022 Leonardo Dessì.

Files are unmodified in content, only re-encoded from UTF-16 to UTF-8 where the originals used it
(`bosses.json`, `graces.json`) for consistency with the rest of this repo.

See `ER_SAVE_PARSING_RESEARCH.md` at the project root for full research notes on the save format.
